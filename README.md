# LSB-стеганография в изображениях BMP

Приложение с графическим интерфейсом (Python + PySide6) для встраивания текстовых
сообщений в изображения BMP методом замены младших битов (LSB) и их извлечения.

## Возможности

- открытие контейнера в BMP или в другом формате (PNG, JPEG, GIF, TIFF, WebP, ICO,
  PPM, TGA и др.) с автоматическим преобразованием в BMP 24 бит; преобразованный
  контейнер можно сохранить кнопкой «Сохранить как BMP…» (прозрачность заменяется
  белым фоном, у анимаций берётся первый кадр);
- выбор цветовых компонент: R, G, B (любая комбинация);
- выбор битовых плоскостей с 1-й (младший бит) по 4-ю (любая комбинация);
- интервал встраивания: в каждый пиксель, через один, через два, через три,
  через четыре пикселя;
- расчёт ёмкости контейнера, контроль длины сообщения;
- оценка искажений: MSE, PSNR, число изменённых пикселей;
- просмотр битовых плоскостей исходного изображения и стегоконтейнера;
- масштаб просмотра «вписать в окно» / 100–800% с синхронной прокруткой исходного
  изображения и стегоконтейнера (при уменьшении большого фото до размера окна
  пиксельные искажения усредняются и становятся незаметны).

## Установка

Готовые установщики — на странице [Releases](../../releases/latest):

- **Windows 10/11 (64 бит):** скачайте `LSB-Stego-Setup-<версия>.exe` и запустите.
  Установщик не подписан цифровой подписью, поэтому SmartScreen может показать
  предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».
- **Ubuntu / Debian (amd64):** скачайте `lsb-stego_<версия>_amd64.deb` и выполните
  `sudo apt install ./lsb-stego_<версия>_amd64.deb`. Приложение появится в меню
  как «LSB-стеганография», запуск из терминала — `lsb-stego`.

## Запуск из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Алгоритм

Пиксели обходятся построчно (слева направо, сверху вниз) с шагом `интервал + 1`.
В каждом используемом пикселе биты записываются в выбранные компоненты в порядке
R → G → B, а внутри компоненты — в выбранные плоскости от младшей к старшей.

Первые 32 бита — длина сообщения в байтах (big-endian), далее — сообщение в UTF-8.
Для извлечения нужно указать те же компоненты, плоскости и интервал, что и при
встраивании. Результат сохраняется как 24-битный BMP (без потерь).
Извлекать можно и из PNG/TIFF (сжатие без потерь), но не из JPEG/WebP:
сжатие с потерями разрушает младшие биты.

## Файлы

- `main.py` — графический интерфейс;
- `lsb_core.py` — алгоритм встраивания/извлечения (независим от GUI);
- `assets/` — значок приложения;
- `packaging/` — сборка установщиков (`build_deb.sh`, `installer.iss`);
- `.github/workflows/release.yml` — сборка `.exe` и `.deb` и публикация релиза
  при отправке тега `v*`.
